#  TechDay Bahia 2026

Um site informativo sobre o **TechDay Bahia 2026**, o maior encontro de tecnologia e inovação de Salvador! Este projeto foi desenvolvido utilizando HTML5 puro como parte do aprendizado de desenvolvimento web.

---

##  Sobre o Projeto

O **TechDay Bahia** é um evento voltado para estudantes, profissionais e entusiastas de tecnologia. O site tem como objetivo apresentar a programação, os palestrantes, as atividades práticas e permitir a inscrição dos participantes.

---

##  Tecnologias Utilizadas

- **HTML5**: Estrutura e marcação semântica da página.
- **Git & GitHub**: Controle de versão e hospedagem do código.
